This directory contains the source files for the project wiki. It is intended for long-form documentation, deep-dives, and community-maintained knowledge.

== Pages

link:Core-Concepts.adoc[Core Concepts]::
Why the suite is shaped this way — declaration versus enforcement, why a new
status code rather than 403/428/451, why purposes rather than identities, why
silence is not refusal, and what failing open costs.

link:Workflows.adoc[Workflows]::
Adopting AIBDP on your own site; verifying that enforcement actually fires
(the most important one, because misconfiguration is silent); working on the
drafts; adding a gate; recording debt.

link:Glossary.adoc[Glossary]::
Protocol terms, behaviour terms, and the estate vocabulary that appears
throughout the repository.
