== What is actually tested

Each gate was demonstrated to fail before being wired. That demonstration is the
evidence; a gate never observed failing is not known to work.

| `single-source` | no `draft-*.xml` at root; no two drafts sharing a base name | a draft copied back to the root

| `no-v2` | no `<section title=>`, `<list>`, `hangText=`, rfc2629 DOCTYPE, bogus namespace | the pre-extraction AIBDP draft (6 failures)

== Gaps

. *No unit tests for the middleware.* `pathMatches`, `getApplicablePolicy`,
  `extractAiPurpose` and `checkPolicyConditions` are only exercised end-to-end
  through five HTTP requests. Glob semantics (`/docs/**`) and exception
  precedence are untested at the unit level.
. *No committed negative corpus.* The five invalid manifests used to prove the
  validator can fail were built ad hoc and discarded. They should live in
  `tests/` so the proof is repeatable rather than anecdotal.
. *No conformance suite.* Nothing lets a third-party implementation demonstrate
  that it resolves policies the same way this one does. Until that exists,
  "interoperable" is untested by construction.
. *`draft-validate` is partial.* Structure is checked; rendering is not, because
  the toolchain question is open. The gate says so rather than implying full
  validation.
. *The Deno path is not exercised in CI.* Only the Bun server is asserted. The
  shared core is runtime-neutral, but "runtime-neutral" is currently a claim
  supported by one local run, not by CI.
