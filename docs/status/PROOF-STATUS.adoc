== Verification that does exist

Proof is not the only evidence. What this project asserts, it asserts in CI, and
each gate was demonstrated to fail before being wired — see `TEST-NEEDS.adoc` for
the failure evidence per gate.

[cols="2,3",options="header"]
|===
| Mechanism | Establishes

| `spec-gates.yml` `draft-structure` | Both drafts are structurally valid RFC-XML v3 and free of v2 constructs
| `spec-gates.yml` `schema-validate` | Every manifest in the tree, including this repository's own, satisfies the published schema
| `spec-gates.yml` `claims-audit` | No governance document asserts a repository path that is absent
| `spec-gates.yml` `enforcement` | The reference implementation returns 430 where the manifest refuses, and 200 where it permits
| `spec-gates.yml` `draft-expiry` | No draft is being presented as current after its expiry date
|===

None of these is a proof. They are falsifiable checks over concrete inputs, which
is the appropriate standard of evidence for a document suite — and a considerably
higher one than the tree had before extraction, when `just check-rsr` validated a
`.well-known/` directory that existed only in a compliance document.
